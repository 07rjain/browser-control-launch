# Browser Control: quiet routing

Preserve the centered hero, feature explorer, compact installation steps, and FAQ. The single expressive element is a generative drawing of browser-like routes that gathers around the product preview. It should suggest many tasks finding one place, rather than add another marketing section.

## Critique before implementation

An animated dot-grid or generic gradient would add decoration unrelated to Browser Control. Replace that first idea with seeded curves whose rounded turns echo tab grouping and browser automation paths. Avoid floating feature cards, extra claims, and perpetual background motion. Draw the routes once; feature changes can replay a short signal. Keep the article illustration unchanged. Keep the original blue video stylesheet independent from the website theme.

## Quality criteria

The artwork must not intercept input, obscure text, produce layout overflow, or run an animation loop after settling. Reduced motion shows a still image. The mobile view uses a quieter crop. Interactive controls retain visible focus and readable contrast.
